# Chrono Desk 0.6.12

Task: CHR-DESK-004. Docs-Impact: LOCAL.

Fix packet operation delivery failing with HTTP 422 after the timing sync
request succeeded. Parsing an empty `bases[].heads` array left a nil Go slice;
serializing the operation for delivery changed `[]` to `null`, violating the
existing operation contract. The parser now preserves the empty array, also
covering operations embedded in the LAN feed. No contract version changes.

The regression reads actual outgoing request bytes, validates them again and
requires the original operation content hash. It failed on the old sender.
Packet upload now requests JSON errors, so server validation messages remain
readable instead of being truncated HTML.

Pending operations retain their stored canonical JSON and unacknowledged state.
Update the existing installation and retry “Отправить на сайт”; no event
reimport, database change or queue reset is needed. Successful HTTP 200 for
the timing request alone does not confirm packet delivery. Field retry and
per-operation receipts must still be checked after installing this release.
