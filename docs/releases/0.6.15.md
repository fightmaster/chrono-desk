# Chrono Desk 0.6.15

Task: CHR-CHIP-002 / CHR-OBS-001. Docs-Impact: CROSS_PROJECT.

This release combines bounded checkpoint reading windows and first/last reading
selection with a local connection timeline. Checkpoints may use an inclusive
absolute/relative upper bound; selecting the last reading requires an upper
bound. Extended export uses schema 4 only when the checkpoint extensions are
needed; existing compatible events retain schema 3. See
[event export](../event-export-format.md).

Live adds a manual connection-history export, diagnostic storage/drop counters
through its existing status request and explicit stale-heartbeat text. Journal
storage is independent of event SQLite and caps two local files at 1 MiB each;
queue capacity is 256, rate ceiling 64 transitions/s. No new polling request,
reader heartbeat field/frequency or automatic upload is introduced.

Existing Feibot heartbeat attributes a socket only to code `U[0-9]{1,12}`.
Before a valid heartbeat the reader is unknown; reconnect creates a new socket
and becomes attributable after heartbeat. This is receiver-local metadata, not
authenticated identity or event authorization. Raw EPCs, participant fields,
frames, addresses, credentials and arbitrary error strings are excluded.
See [connection diagnostics](../connection-diagnostics.md).

Dependencies are immutable published rfid-core 0.5.0 and timing-core 0.12.0.
macOS 11 support retains Go 1.24.13. Existing documented standard-library
security debt remains; this release does not claim that a platform upgrade was
performed. Installation on field Mac/Windows is separate from publication. The checkpoint
window browser regression is included in local and official CI quality gates.
