# Chrono Desk 0.6.10

Task: CHR-DESK-002. Docs-Impact: LOCAL.

Fix HTTPS site connections failing with `packet relay enrollment unavailable`
and `malformed HTTP response "\x00\x00..."`. Go 1.24's cloned default transport
retained `h2` in its TLS ALPN list even though Desk selected an HTTP/1.1-only
parser. The client now advertises only `http/1.1`, matching that parser.
The shared transport serves packet enrollment, roster/operation/feed exchange
and ordinary event synchronization.

TLS certificate verification, explicit endpoint authentication and the redirect
ban remain enabled. A real TLS regression test reproduces the original binary
HTTP/2 response and covers successful requests to both HTTP/1.1-only and
HTTP/2-capable servers. No database or wire-contract migration is required.

After updating, set the site address to `https://app.chrono.events`, save it,
and retry connecting packet issuance in the existing event. Packet enrollment
requires the Chrono admin surface; the public `https://chrono.events` host
returns 404 after authentication. No reimport is required.

The required vulnerability audit still reports 15 existing Go standard-library
findings on the pinned Go 1.24.13 toolchain, retained for macOS 11 support.
This release does not upgrade dependencies or enable HTTP/2.
