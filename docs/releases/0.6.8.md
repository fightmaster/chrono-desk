# Chrono Desk 0.6.8

Task: CHR-DESK-001. Docs-Impact: LOCAL.

The Live manual timing screen shows a stable ordinal for each captured finish
without a participant number. It also shows the last assigned ordinal and the
number of captures still awaiting a participant. The same ordinal appears in
the capture drawer. The counter survives restart and does not reuse numbers
after a capture is assigned or deleted.

The ordinal is a judge-facing marker, separate from the participant bib. No
timing observation, site-sync payload, or database schema changes in this
release.
