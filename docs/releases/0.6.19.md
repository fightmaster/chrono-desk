# Chrono Desk 0.6.19

Task: CHR-SSE-001. Docs-Impact: LOCAL.

The LAN presenter at `/live` now receives the latest ten confirmed finishes over
SSE immediately after committed finish changes. There is no500ms batching wait
and no idle snapshot polling. Clients sharing a distance reuse a snapshot; a slow
client has one pending frame and cannot block RFID/sidecar processing or another
client. Heartbeats indicate connection health without redrawing cards.

**Обновить**, returning from Protocol, changing distance, returning to a visible
tab and reconnecting all obtain fresh data. Hidden/inactive views close their
stream. Club, Team, city, time, gender/category places, scroll anchors and
participation-key deduplication remain. Old-server polling compatibility remains.

This release also packages the canonical Club display/edit and bundled-card
owner/refresh-counter fixes from main since the preceding tagged release.
Shared timing-core0.13.0, rfid-core0.5.0, schema5, gun/chip/assigned-start behavior,
observation ownership and site-sync/export contracts are unchanged.

The platform release uses Go1.24.13 for macOS11 Intel and builds Windows amd64.
Existing Go1.24 standard-library findings remain tracked as CHR-SEC-002; this is
not a toolchain/security-debt fix. No database migration is required. The previous
app can be retained for rollback; user event files are not modified by installing
the bundle. Venue Wi-Fi/battery measurements remain distinct from synthetic
runner evidence.
