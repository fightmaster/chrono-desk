# Chrono Desk 0.6.11

Task: CHR-DESK-003. Docs-Impact: LOCAL.

The packet issuance certificate button now saves `chrono-desk-ca.crt` through
Desk's native Downloads export mechanism, as existing JSON/CSV exports do.
Browser Blob downloads were silently ignored in the embedded desktop webview.
The UI shows the saved path, disables the button while saving and reports
filesystem errors. If Downloads is absent, the existing export mechanism
falls back to the home directory; the UI shows the actual destination.

Transfer this public CA certificate to each tablet and install it as trusted
to connect to this Desk over local HTTPS. Keep the computer and tablets on
the same LAN. This action does not install trust automatically. It exports
only the existing public certificate and preserves the installation's keys.

The export endpoint belongs to the authenticated localhost control API;
packet LAN and site contracts are unchanged. Site enrollment still requires
`https://app.chrono.events`.
