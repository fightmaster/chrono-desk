# Chrono Desk 0.6.1

Task: CHR-SW-019
Docs-Impact: LOCAL

Includes the current published main baseline and regression coverage for site
roster additions during issuance. Existing feed v1 creations preserve local
issuance and are forwarded to enrolled LAN tablets. No protocol or database
migration is introduced by this compatibility check.

Go remains pinned to 1.24.13 for macOS 11 compatibility. Release binaries and
checksums are built by the existing GitHub workflow; a local version bump is not
proof that those jobs or desktop installation have completed.
