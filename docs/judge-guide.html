Chrono Desk — руководство судьи

Офлайн-замена сайта chrono.events на старте: приём отсечек, ручные финиши, протоколы и экспорт — без интернета.

Актуально для версии приложения v0.3.x (версия видна в левом верхнем углу окна — v0.3.0+NN). Экраны ниже — точные отрисовки интерфейса (светлая тема приложения); при необходимости любой блок можно заменить реальным скриншотом. Файл хранится в репозитории (docs/judge-guide.html) и обновляется вместе с приложением.

0Что это и когда нужно

Chrono Desk заменяет сайт chrono.events в зоне без интернета. Сайт остаётся главным источником данных: вы выгружаете событие с сайта, работаете офлайн, а потом (когда появится связь) отправляете изменения обратно.

  • Одно событие = один файл .chrono. Его можно переносить на флэшке между ноутбуками; резервная копия — это просто копия файла.
  • Результаты пересчитываются офлайн из отсечек считывателя и ручных финишей судьи.
  • Судейские правки сохраняются и при следующем импорте накладываются поверх данных сайта («локальные правки побеждают»).

1Запуск и загрузка события

  1. На стартовом экране — список событий с подписью «N дистанций · M участников».
  2. Нет события на ноутбуке — импортируйте выгрузку с сайта (.json). Импорт атомарный: либо целиком, либо ничего.
  3. Файл .chrono уже есть — откройте его из списка.
  4. Выберите событие → откроется рабочая область с вкладками Live и Результаты.
СоветПовторный импорт той же выгрузки безопасен: данные сайта обновятся, а локальные правки сохранятся.

2Приём считывателя (Live)

На вкладке Live приложение принимает отсечки от считывателя Feibot по сети (TCP) в реальном времени и сразу пересчитывает результаты.

  1. Нажмите Запустить приём — появится индикатор LIVE.
  2. Следите за состоянием: заряд, число меток и «свежесть» (heartbeat N с назад). Оранжевый цвет давности (>30 с) — связь с прибором потеряна.
  3. В ленте идут чтения чипов; ручные финиши помечены «ручной финиш».
ВажноЕсли приём остановился, под кнопкой будет показана причина. Опрос состояния в шапке — это лишь обновление картинки; сами отсечки приходят на ноутбук сразу, по сети от прибора.

3Ручные финиши

Если чип не сработал, судья вводит финиш вручную. Ручной финиш авторитетный: переживает пересчёты и накладывается поверх чиповых данных.

Ввод по номеру/фамилии

  1. На Live найдите участника по номеру или фамилии.
  2. Выберите режим: чистое время (например 00:47:13.250) или время суток (ЧЧ:ММ:СС.ммм).
  3. Подтвердите — запись появится в ленте с возможностью удалить.
Предупреждение о дублеЕсли у номера уже есть ручной финиш — появится предупреждение. При пересчёте у участника засчитывается первая запись (как у чипа); лишнюю удалите из ленты.

Зафиксировать время сейчас, номер — потом

  1. Нажмите ⏱ Зафиксировать время — момент сохранится как «захват» без номера (не теряется при перезапуске).
  2. Позже откройте захват и привяжите номер — создастся ручной финиш, захват исчезнет.

Изменить или снять номер

Откройте участника с ручным финишем → Изменить номер — откроется поиск:

  • Выбрать другого участника → финиш перейдёт к нему (время сохранится).
  • Закрыть без выбора → номер снимется, а время вернётся в «захваты» без номера. Так участника убирают с этого времени, ничего не теряя.

Поправить время

В открытой карточке измените поле «Время финиша» — меняется только эта запись, соседние не трогаются.

4Импорт с флэшки (CSV)

Когда отсечки сняты на флэшку (формат Feibot), их можно загрузить файлом.

  1. Выберите CSV-файл.
  2. Укажите код считывателя и часовой пояс (из списка российских зон) — обязательно: в CSV время записано без зоны.
  3. Нажмите Загрузить — появится отчёт: разобрано / добавлено / дубликаты / ошибки строк.
Часовой пояс обязателенБез пояса импорт не выполнится — иначе все отсечки сдвинулись бы на смещение зоны.

5Результаты и протокол

Выберите дистанцию. В шапке — «финишировало X из Y» (Y — стартовый список, X — у кого есть место).

Старт дистанции

  • Правка времени старта запускает автопересчёт и сдвигает старты всех участников на ту же величину.
  • ⏱ Старт сейчас — ставит текущее системное время (с миллисекундами) как старт. Нажимайте по сигналу.

Возрастные группы

  • У участника в списке — только группы, привязанные к его дистанции.
  • «+ добавить из каталога» — привязать существующую группу. Открепить можно, только если в ней нет участников этой гонки.

Чекпоинты

В настройках дистанции можно править чекпоинты (тип START/CHECKPOINT/FINISH, привязку к прибору, окна активации) — прямо у готовой строки. Изменения требуют пересчёта.

7Экспорт и бэкап

  • Протокол Excel (.xlsx) — колонки повторяют формат сайта; путь к файлу показывается после экспорта.
  • Бэкап — снимок .chrono и выгрузка в контрактном JSON.

8Трансляция результатов по сети

Когда интернета нет, результаты есть только на ноутбуке. Чтобы их видели те, кто подписывает грамоты, гравирует время на медалях или ведёт соцсети, включите раздачу по локальной сети: Настройки события → «Трансляция результатов по сети» → «Включить трансляцию».

  • Появятся адрес(а) (например http://192.168.1.50:8090) и QR-код для каждого. Подключите телефон к той же сети Wi-Fi и откройте адрес или отсканируйте QR. Если адресов несколько (например ноутбук подключён и по кабелю, и по Wi-Fi) — выберите тот, что в вашей сети; у каждого свой QR.
  • Открывается страница только для просмотра: дистанция выбирается из списка, а ниже — две вкладки как в приложении: «Призёры» (абсолют М/Ж и призёры по возрастным группам) и «Протокол» (полная таблица с поиском по фамилии или номеру). Страница сама обновляется по мере пересчёта.
  • Для СММ: на вкладке «Призёры» есть кнопка «Скопировать список призёров (для Telegram)» — она кладёт в буфер готовый текст (Markdown) с победителями и призёрами дистанции, чтобы не перепечатывать ФИО вручную. Если телефон не даёт копировать сам, появится окно с текстом — выделите и скопируйте.
  • Никаких правок и без даты рождения — наружу уходит только то, что нужно для табло и наград.
  • Транслируется одно выбранное событие. «Выключить трансляцию» закрывает доступ из сети.
СетьВсе устройства должны быть в одной Wi-Fi. Если адрес не показан — проверьте подключение ноутбука к сети. Порт по умолчанию 8090 (меняется переменной CHRONO_PUBLIC_PORT).

9Синхронизация на сайт

Когда появится интернет, локальные изменения (отсечки, новые участники, правки, ручные финиши) можно отправить на сайт chrono.events. Сайт применит их идемпотентно; разрушительные действия — только в режиме перезаписи. Сайт остаётся главным источником данных.

ПорядокСверяйтесь с ответственным за сайт: сначала отправка с ноутбука, затем при необходимости повторная выгрузка и реимпорт — локальные правки сохранятся.

10Подсказки и решение проблем
